# START HERE — 10 Steps in the Correct Order

**This pack includes plans, prompts and resources; application code has NOT been generated.**

1. Download/extract ZIP to `C:\Projects\OrderFlow`.
2. Open that folder in Antigravity IDE.
3. Turn on **Request Review** for terminal commands and artifact changes.
4. Open/read `AGENTS.md` and `docs/ORDERFLOW_MASTER_SPEC.md`.
5. Paste the content of `prompts/00_BOOTSTRAP_AND_REVIEW.md` into the Agent chat.
6. Review plan for `OF-000`; approve only the documentation/environment validation.
7. Once approved, choose `prompts/tasks/OF-001.md` to begin the **Core Java CLI Maven lab**.
8. At each task: ask for theory → code exercise → your attempt → review/test → progress log → approved commit.
9. Complete backlog `OF-001` through `OF-035` in sequence. Study all 23 pattern labs via `docs/DESIGN_PATTERNS_LEARNING_TRACK.md`, **without** forcing every pattern into production code.
10. Begin future Antigravity sessions with `prompts/03_RESUME_SESSION.md`.

### Project stages

- Core Java: OF-001 through OF-011
- Spring and database: OF-012 through OF-019
- Security and architecture: OF-020 through OF-024
- Concurrency and distributed workflows: OF-025 through OF-030
- Production: OF-031 through OF-034
- Portfolio: OF-035; optional extensions: OF-036
