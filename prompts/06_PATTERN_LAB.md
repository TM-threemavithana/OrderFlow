# Use for a GoF design-pattern learning lab

Teach me the [PATTERN-NAME] pattern using a tiny pure Java exercise under `learning-labs/design-patterns/[pattern-name]/`.

First explain: problem before the pattern; intent and participants; UML sketch; minimal Java implementation idea; a specific OrderFlow applicability example and when NOT to use it; alternatives; tests; and 3 interview questions.

Let me implement the first version. Review code and tests. Keep this lab isolated unless a real production requirement already justifies the pattern. Record completion only after explaining it myself. Do not automatically apply the pattern throughout OrderFlow.
